# 金蝶成本核算工具（Windows exe）

给财务同事用的内部小工具：双击 exe → 输入**自己的**金蝶账号和密码 → 点「登录并自检」，
确认账号能否正常读取**销售订单、采购订单、物料清单**三张表单。

- 服务器地址、账套 ID **已固定在代码里**（`selfcheck.py` 的 `FIXED_CONFIG`），界面上不可修改
- 所有操作都是**只读查询**（不新增 / 不修改 / 不删除任何单据）
- 密码只放在内存里使用，**不保存到磁盘、不写日志**

## 目录内容

| 文件 | 作用 |
|---|---|
| `app.py` | 图形界面主程序（tkinter，Python 自带） |
| `selfcheck.py` | 固定配置 + 登录自检逻辑（与界面无关，可单独运行） |
| `build.bat` | Windows 一键打包脚本（产出单文件 exe） |
| `requirements.txt` | 运行需要的第三方库（requests） |
| `_smoke_check.py` | 打包前自查脚本（语法检查 + 界面构建 + 登录自检，可选） |

> 本工具复用仓库上一级的 `kingdee_sdk`（打包脚本用 `--paths ".."` 把它一起打进 exe），
> 所以打包时**整个仓库要在同一台机器上**，目录结构不要拆散。

## 一、在 Windows 上打包（只需做一次）

1. 安装 Python 3.11 或更高版本：<https://www.python.org/downloads/windows/>
   - ⚠️ 安装界面**务必勾选** `Add python.exe to PATH`
2. 把整个项目文件夹拷到 Windows 机器上（例如 `D:\kingdee_webapi_sdk`）
3. 双击 `windows_tool\build.bat`，等它自动完成（第一次装 PyInstaller 会慢一些）
4. 打包产物：`windows_tool\dist\KingdeeCostTool.exe`
   - 可以改名成中文，比如 `金蝶成本核算工具.exe`

打包出来的 exe 已经内置 Python 和依赖，**财务的机器不需要装任何环境**。

## 二、财务同事怎么用

1. 把 exe 拷到电脑上（**必须在公司内网**，要能访问 `http://192.168.0.200`）
2. 双击运行 → 输入自己的金蝶账号和密码 → 点「登录并自检」（或直接按回车）
3. 看「运行结果」：
   - 三张表单都显示 `[通过]` → 账号没问题，可以正常取数
   - 出现 `[失败]` → 把窗口内容截图或复制发给管理员

## 三、命令行排查（可选）

不想开界面时，可以在命令行里直接自检：

```bat
:: 推荐用环境变量传密码，避免留在命令历史里
set KINGDEE_USERNAME=你的账号
set KINGDEE_PASSWORD=你的密码
KingdeeCostTool.exe --check
```

源码环境下等价命令：

```bat
cd windows_tool
python app.py --check
python app.py --smoke-gui   :: 只验证界面能否启动
python _smoke_check.py      :: 打包前一次性自查（语法 + 界面 + 登录自检）
```

## 四、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 提示「登录失败：用户名或密码错误」 | 账号或密码不对，或账号被锁定，先在金蝶客户端试一次登录 |
| 提示网络请求失败 / 超时 | 不在公司内网，或服务器地址变了（见下） |
| 三张表单里某个显示 `[失败]` | 该账号对这张表单没有查询权限，把窗口内容发给管理员开权限 |
| 双击 exe 没反应 | 杀毒软件拦截（PyInstaller 产物常见误报），加白名单；或先看日志文件 |
| 日志在哪 | `%TEMP%\kingdee_tool.log`（界面上的「打开日志文件夹」按钮可直接打开） |
| 窗口标题里的版本号 | 改 `selfcheck.py` 的 `APP_VERSION` 后重新打包即可 |

## 五、要改东西时改哪里

| 想改什么 | 改哪里 |
|---|---|
| 服务器地址 / 账套 ID | `selfcheck.py` → `FIXED_CONFIG` |
| 自检哪几张表单 | `selfcheck.py` → `SELFCHECK_FORMS` |
| 界面文字、按钮布局 | `app.py` → `ToolApp` |
| 以后加「成本核算 / 导出 Excel」按钮 | 口径确定后在 `app.py` 里新增按钮，调用新的核算模块 |

改完代码要**重新跑一次 `build.bat`** 才会生效（exe 是打包时的代码快照）。
