# 金蝶成本核算工具（Windows exe）

给财务同事用的内部小工具：

```
双击 exe → 输入自己的金蝶账号密码 → 「登录并自检」确认能取数
   ↓
填「统计区间」（整月，或 5 号~15 号这种任意区间）→「开始核算并导出 Excel」
   ↓
如果扫描出「缺采购价」的子件：
   工具把这些料号预填进本地维护表 CSV，并弹出清单提示补价
   ⛔ 补完之前不导出最终表格
   ↓
用 Excel 打开维护表，在缺价料号那一行的「未税单价 / 含税单价」里填价并保存
   ↓
回到工具点「重新检查」（不用重新登录金蝶，秒级）→ 全部补齐后导出最终表格
```

- 服务器地址、账套 ID **已固定在代码里**（`selfcheck.py` 的 `FIXED_CONFIG`），界面上不可修改
- 所有操作都是**只读查询**（不新增 / 不修改 / 不删除任何单据）
- 密码只放在内存里使用，**不保存到磁盘、不写日志**

## 一、核算口径（与财务确认，2026-09）

| 项 | 口径 |
|---|---|
| 统计区间 | **任意起止日期**（整月，或 2026-09-05 ~ 2026-09-15 这种），区间内**每一条销售记录单独计算** |
| 销售取价 | 销售订单的「单价」列（未税 `FPrice` / 含税 `FTaxPrice`，界面上可切换） |
| 采购取价 | 该物料**最近一次成交价**（最新一条已审核采购行，不限时点；单价为 0 的行不算成交） |
| 外币处理 | 按**结算币别**折算人民币（默认用单据自带汇率，可在界面上填「覆盖汇率」整批指定） |
| 成本口径 | 销售产品的 BOM 递归展开到「没有 BOM 的叶子件」，叶子件用量 × 单价汇总 |
| **缺价子件** | 金蝶取不到采购价的子件 → **工具把料号预填进维护表，财务手工填单价**；<br>成本分三列：**自动料本（金蝶）+ 手工维护料本（手工填的）= 最终料本** |
| 取价优先级 | **金蝶价优先**：金蝶有价就用金蝶价；只有金蝶取不到价时才用手工维护价 |
| 导出卡口 | 还有缺价子件没填价时**不导出最终表格**（可点「仍有缺价也导出（按 0 计）」强制导出，Excel 里会标注） |

## 二、目录内容

| 文件 | 作用 |
|---|---|
| `app.py` | 图形界面主程序（tkinter，Python 自带） |
| `selfcheck.py` | 固定配置 + 登录自检逻辑（与界面无关，可单独运行） |
| `build.bat` | Windows 一键打包脚本（产出单文件 exe） |
| `requirements.txt` | 运行需要的第三方库（requests、openpyxl） |
| `_smoke_check.py` | 打包前六项自查脚本（语法 / 主界面 / 缺价对话框 / 离线逻辑 / 登录 / 核算） |

> 本工具复用仓库上一级的 `kingdee_sdk`（打包脚本用 `--paths ".."` 把它一起打进 exe）。
> **核算逻辑不在本目录**，在 `../kingdee_sdk/costing.py`；**维护表逻辑**在 `../kingdee_sdk/manual_prices.py`
> ——所以打包时**整个仓库要在同一台机器上**，目录结构不要拆散。

## 三、在 Windows 上打包（只需做一次）

1. 安装 Python 3.11 或更高版本：<https://www.python.org/downloads/windows/>
   - ⚠️ 安装界面**务必勾选** `Add python.exe to PATH`
2. 把整个项目文件夹拷到 Windows 机器上（例如 `D:\kingdee_webapi_sdk`）
3. 双击 `windows_tool\build.bat`，等它自动完成（第一次装 PyInstaller 会慢一些）
4. 打包产物：`windows_tool\dist\KingdeeCostTool.exe`
   - 可以改名成中文，比如 `金蝶成本核算工具.exe`

打包出来的 exe 已经内置 Python 和依赖，**财务的机器不需要装任何环境**。

> ⚠️ **改了代码必须重新跑 `build.bat`** 才会生效（exe 是打包时的代码快照）。

## 四、财务同事怎么用

### 1. 登录并自检

把 exe 拷到电脑上（**必须在公司内网**，要能访问 `http://192.168.0.200`）→ 双击运行 →
输入自己的金蝶账号和密码 → 点「登录并自检」：三张表单都显示 `[通过]` 说明账号能取数
（有 `[失败]` 就把窗口内容发给管理员）。

### 2. 填统计区间并核算

- **统计区间**：填起止日期，如 `2026-09-01` ~ `2026-09-30`（整月）；
  也可以只算一段，如 `2026-09-05` ~ `2026-09-15`。快捷按钮：`本月` / `上月`
- **计价方式**：未税 / 含税（默认未税）
- **覆盖汇率**：留空 = 用单据自带汇率；外币要整批按某个汇率折算时才填，如 `6.7809`
- 点「开始核算并导出 Excel」→ 工具开始取数（记录条数越多越慢，进度看「运行结果」窗口）

### 3. 如果提示有子件缺采购价（重要）

工具会弹出「缺采购价子件」窗口，列出所有金蝶里取不到价的子件（料号、名称、单位、出现次数）。
同时**这些料号已经自动预填进维护表**：

```
<exe 所在目录>\成本核算数据\采购价维护表.csv
```

处理办法：

1. 点窗口里的「**打开维护表填写**」（或自己用 Excel 打开那个 CSV）
2. 找到对应料号那一行，在**「未税单价」/「含税单价」**列里填价
   （工具已经填好了料号、名称、单位，**单价列是空的，直接往后填就行**）
3. 保存并关闭 Excel（工具下次要写这个文件，Excel 占着会写不进去）
4. 回到工具点「**重新检查（读维护表）**」
   - 还有没填的 → 窗口会刷新，继续填
   - 全部补齐 → 提示「所有子件都有价了」，点「是」即导出最终表格

> - 维护表是**本地长期产物**：填过的价会一直留着，下次核算自动套用，不用重复填
> - 表里人民币以外的币别，请在「币别」列填币别（如 `美元`），并在「汇率」列填折算汇率
> - 只填「未税单价」或只填「含税单价」都可以，但**必须和你选的计价方式一致**
>   （选了未税就填未税单价），否则会被当成没填
> - 想核对**全部子件**（不只是缺价的）的价格来源，勾上窗口左下角的
>   「显示全部子件（含已有价的）」
> - 如果某个子件确实永远拿不到价，可以点「仍有缺价也导出（按 0 计）」，Excel 里会标注出来

### 4. 补完价之后不想重新登录取数？

- **主界面**：点「套用维护表重新导出（不用登录）」——用上次取数的结果 + 最新维护表秒级重算并导出
- 或者直接点「重新检查」（缺价窗口里）

> 重算只能用于「上次取数」的同一个区间和同一个计价方式。改了计价方式（未税↔含税）或覆盖汇率，
> 必须重新点「开始核算并导出 Excel」取数（工具会提示）。

### 5. 导出结果

结果导出到**桌面**，文件名形如 `成本核算_2026-09_未税.xlsx`
（区间导出是 `成本核算_2026-09-05_2026-09-15_未税.xlsx`；强制导出会带 `_含缺价`）。

| 工作表 | 内容 |
|---|---|
| **逐条核算** | 每条销售记录一行：产品、数量、售价、**自动料本 / 手工维护料本 / 最终料本**、毛利、毛利率、备注 |
| **区间汇总** | 按产品汇总：记录数、数量、销售额、自动料本、手工维护料本、最终料本、毛利、毛利率（末行合计） |
| **子件价格总览** | 本次涉及**全部子件**（去重）：价格来源、单价、出现次数、涉及产品数（缺价的排最前） |
| **子件明细** | 每条记录用到的每个叶子件：累计用量、单价、金额、采购单号、**价格来源**（金蝶 / 手工维护） |
| **缺价待维护** | 导出时仍缺价的子件清单（正常流程下为空） |
| **说明** | 本次核算的参数与口径（区间、计价方式、汇率、维护表位置等） |

## 五、命令行排查（可选）

不想开界面时可以在命令行直接跑（源码环境下）：

```bat
cd windows_tool
python app.py --check                              :: 只做登录 + 三表单自检
python app.py --costing --month 2026-09             :: 无界面核算（整月）
python app.py --costing --from 2026-09-05 --to 2026-09-15
python app.py --costing --recheck                   :: 不登录，用上次快照 + 维护表重算并导出
python app.py --costing --month 2026-09 --allow-missing   :: 有缺价也导出
python app.py --smoke-gui                           :: 只验证主界面能否启动
python app.py --smoke-dialog                        :: 只验证缺价补全对话框（假数据）
python _smoke_check.py --month 2026-09              :: 打包前一次性自查（六项）
```

exe 同理：`KingdeeCostTool.exe --costing --month 2026-09`。口令建议用环境变量传，避免留在命令历史：

```bat
set KINGDEE_USERNAME=你的账号
set KINGDEE_PASSWORD=你的密码
KingdeeCostTool.exe --costing --month 2026-09
```

退出码：`0` 成功导出；`1` 参数/运行错误；`2` 缺价子件未补齐（已更新维护表、**未导出**）。

## 六、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 提示「登录失败：用户名或密码错误」 | 账号或密码不对，或账号被锁定，先在金蝶客户端试一次登录 |
| 提示网络请求失败 / 超时 | 不在公司内网，或服务器地址变了（见第七节的改动表） |
| 三张表单里某个显示 `[失败]` | 该账号对这张表单没有查询权限，把窗口内容发给管理员开权限 |
| 弹出「缺采购价子件」窗口 | 正常流程：在维护表里给这些料号填单价 → 点「重新检查」 |
| 提示「维护表保存失败…如果它正被 Excel 打开」 | 先关掉 Excel，再点一次（工具只在扫描时写维护表） |
| 填了价但「重新检查」后还是缺 | ① 计价方式对不上（选了未税要填「未税单价」）② 料号被改动过 ③ 价格填成了文字（如 `12元`） |
| 维护表里填了价，但结果还是用金蝶价 | **金蝶价优先**：金蝶已经有该子件的采购价时，手工价不生效；「说明」工作表里会列出这些料号，可以删掉维护表对应行 |
| 某条记录「备注」写着「N 个子件缺采购价」 | 这些子件成本按 0 计（**毛利会偏高**）——正常流程下应先在维护表补价 |
| 某条记录「备注」写着「未取到子件」 | 该产品没有 BOM，需要研发先维护物料清单 |
| 毛利为负（亏本） | 可能真亏，也可能因为采购价取的是「最近一次成交价」（可能是很久以前的老价） |
| 导出 Excel 失败 / 提示缺 openpyxl | 打包机器上 `python -m pip install openpyxl`，然后重新跑 `build.bat` |
| 双击 exe 没反应 | 杀毒软件拦截（PyInstaller 产物常见误报），加白名单；或先看日志文件 |
| 日志在哪 | `%TEMP%\kingdee_tool.log`（界面上的「打开日志文件夹」按钮可直接打开） |

## 七、要改东西时改哪里

| 想改什么 | 改哪里 |
|---|---|
| 服务器地址 / 账套 ID | `selfcheck.py` → `FIXED_CONFIG` |
| 自检哪几张表单 | `selfcheck.py` → `SELFCHECK_FORMS` |
| 核算口径（取价规则、BOM 展开、缺价处理） | `../kingdee_sdk/costing.py` → `CostingCalculator` |
| 维护表列 / 存放位置 / 编码 | `../kingdee_sdk/manual_prices.py` → `CSV_HEADERS` / `candidate_data_dirs` |
| 导出 Excel 的列 / 工作表 | `../kingdee_sdk/costing.py` → `_finalize()` 拼的行 + `export_xlsx()` |
| 界面文字、按钮布局、缺价对话框 | `app.py` → `ToolApp` / `MissingPriceDialog` |
| exe 名字 | `build.bat` 里的 `--name` |

改完代码要**重新跑一次 `build.bat`** 才会生效（exe 是打包时的代码快照）。

## 八、当前版本范围

`v0.3.0`：登录 + 三表单自检 + **按任意日期区间逐条成本核算** + **缺价子件手工维护表（补全才允许导出）**
+ 导出 Excel（逐条核算 / 区间汇总 / 子件价格总览 / 子件明细 / 缺价待维护 / 说明）。

维护表与快照的位置（按优先级，优先复用已有维护表的目录）：

1. 环境变量 `KINGDEE_COSTING_DATA_DIR`
2. exe 所在目录下的 `成本核算数据\`（源码环境是仓库根目录）
3. 用户主目录下的 `金蝶成本核算\`（exe 放在只读目录 / 网络盘时回退到这里）

已知限制（按财务口径有意为之，如需调整请告知）：

1. 采购价取「最近一次成交价」**不限时点**，所以可能用到很久以前的老价。
2. 叶子件按「没有 BOM 就算采购件」，若某自制件没维护 BOM，会被当成采购件；
   它也会出现在缺价清单里，需要财务给个估价（或点强制导出按 0 计）。
3. 「当月初汇率」账套里没有汇率表数据源，所以默认用**单据自带汇率**（下单日汇率），
   需要月初汇率时用「覆盖汇率」手工填。
4. 未处理**单位换算**（BOM 用量单位与采购单位不同时会有偏差），明细里有「单位」列供人工核对。
5. 维护表是 CSV：用 Excel 编辑时**不要改表头文字**（改了一部分别名也能认）、
   不要把「料号」列改成数字格式、不要在单价单元格里写「元」等单位。
